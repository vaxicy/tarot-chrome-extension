## 返回按钮最终形态 + 星空粒子背景（commit 0cf2688 / 9176142 / 9f7ff66）

- 返回按钮迭代 3 轮定稿：胶囊「← 返回」→ 30px 圆框箭头 → **最终：无边框透明底 28×28 + 内联 SVG chevron（polyline 10,3→4,8→10,13，stroke=currentColor 1.8px）**。用户否决了带外框/胶囊样式。
- hover 用户拍板「简单一点」：scale(1.15) + opacity 0.85，不要背景高亮。
- 星空背景升级三层视差粒子（用户要「粒子浮动」感）：
  1. body::before 大星点 2px，background-size 400×620 repeat + top:-100% + translateY 50% 上漂 120s
  2. body::after 小星尘 1px，反向下漂 160s + starTwinkle 5s
  3. .starfield 高亮点缀层（popup.html body 首位，aria-hidden）starPulse 7s 错峰脉冲
  - 无缝循环原理：容器 200% 高 + repeat 平铺 + translateY(±50%)。
- 教训：popup.css 旧中文注释是 GBK 乱码字样，replace_in_file 匹配时必须先 read_file 精确复制，凭记忆重写会失配。

## hover 外框反复修不掉的根因（commit 9983cd2→399a230→001a590→961b44d）

- 用户连续 3 轮反馈「hover 还有外框」，前 3 次都在 `.page-back-btn:hover` 上加覆盖（box-shadow:none / background:transparent 等）都没用。
- **真正根因**：popup.css 里残留了第一轮胶囊按钮迭代的**第二个 `.page-back-btn:hover` 块**（background: rgba(255,215,0,0.18) + border-color），位于新规则之后，同优先级下 CSS 后者覆盖前者——新 hover 规则写在前面全被它盖掉。
- 教训：改样式反复不生效时，第一件事 `search_content` 搜选择器**列出所有匹配行**，确认没有同选择器重复块残留在文件更后面，而不是继续往规则里加覆盖属性。
- 最终形态：hover 仅 scale(1.15) + opacity 0.85，无背景/阴影/边框/outline；::before 扫光 display:none；focus outline 也清掉。
- 粒子速度：大星点 40s / 小星尘 55s（用户嫌 120s/160s 太慢）。
