# 2026-09-01 Magic Tarot Popup Fix (Round 2)

## Round 1 (reverted as `84db418`)

First attempt broke the popup entirely by forcing `min-width: 420px` on the
popup body. The popup went from "narrow + flashing" to "64x100 purple blob
with no text". Root cause for the collapse was actually `:root` typed as
`::root`, plus a UTF-8 BOM at the start of `popup.css`.

The user's screenshot showed the popup reduced to ~64x100 pixels with only
the three tool cards partially visible. Lesson: **never apply
`min-width: <px>` to the popup body in an extension popup**, it conflicts
with Chrome's own width clamping.

## Round 2 (current, committed `9033802`)

Real fixes that don't change popup sizing:
- Fix `::root` -> `:root` in `popup.css` (the actual CSS bug that disabled
  all `--color-*` and `--popup-*` variables).
- Remove the UTF-8 BOM at the top of `popup.css` via a small Python script
  (`fix_root2.py`); it could interfere with `body::before` selectors.
- Hide `.tool-card-icon` (`display: none`) and remove the `<span>` emoji
  elements from `popup.html` so the tool cards stay balanced.
- Enlarge `.tool-card-label` 11->13px and `.tool-card-sub` 9->11px to
  keep them legible without the emoji.

**Verification**: `git diff popup.html popup.css` shows only the safe local
changes; popup body width is unchanged.
