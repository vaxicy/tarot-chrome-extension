## 设计风格

### 色彩方案
- **主背景**：深紫/深蓝渐变 `#1a0a2e` → `#16213e`（匹配扩展暗色魔法主题）
- **强调色**：金色 `#ffd700` / 紫罗兰 `#9b59b6` / 星光白 `#e8d5f5`
- **文字**：白色主文 `#ffffff`、浅灰副文 `#c0b8d8`
- **卡片背景**：半透明紫 `rgba(155,89,182,0.15)` + 圆角边框

### 字体
- **中文**：微软雅黑 / 苹方（系统默认黑体）
- **英文**：Segoe UI / Inter
- **标题**：加粗 28–36px
- **正文**：常规 16–20px
- **标注**：12–14px

### 视觉元素
- 扩展图标（icon128.png）作为品牌标识
- 星星 ✨ 月亮 🌙 卡牌 🎴 魔法 ⚡ 等魔法主题 emoji 点缀
- 微妙的星光/粒子效果（用小圆点模拟）

## 技术要求

- 格式：PNG（24 位，无 alpha 通道或保留 alpha 均可）
- 分辨率：@1x（标准屏幕）
- 色彩空间：sRGB
- 文件大小：单张截图 ≤ 1MB（推荐）
